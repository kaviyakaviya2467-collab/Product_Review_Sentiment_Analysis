# Product Review Sentiment Analysis

##  Project Overview
A Machine Learning and NLP project that analyzes customer product reviews and classifies them into **Positive, Neutral, and Negative** sentiments using **Transformer embeddings**.

##  Objective
To automatically understand customer feedback and identify sentiment from product reviews.

##  Technologies
- Python
- Pandas & NumPy
- Scikit-learn
- Sentence Transformers
- Matplotlib & Seaborn

##  Models Used
- Random Forest + Transformer
- Gradient Boosting + Transformer

##  Results
**Random Forest + Transformer** achieved the best performance:
- Test Accuracy: **86.6%**
- F1 Score: **81.8%** :contentReference[oaicite:0]{index=0}

##  Workflow
**Data Cleaning → EDA → Transformer Embeddings → Model Training → Evaluation → Sentiment Prediction**
